# Welcome to Tzara

This is your **main** vault's start page. Everything here is an ordinary markdown file on disk - edit it, delete it, or replace it entirely. 

## Getting started

- Create a new page by adding a `.md` file to this vault (or use the editor).
- Link between pages with Obsidian-style wikilinks: `[[Some Page]]`.
- Drop images and attachments alongside your notes and reference them inline.
- Browse the [Help](/wiki/{{system_vault}}/help) documenation for more information. 

> [!tip]
> Edit an existing page and create a wikilink for a new page you want to create.  Save your edits, and then click on the link you just added to easily create your new page.
